 Snake & Apples 🎮🐍

A classic Snake game implemented in HTML, CSS, and JavaScript, playable on both desktop and mobile devices. Includes touch controls, swipe gestures, and bonus golden food!

---

## Features

- 🟢 **Classic Snake Gameplay:** Grow the snake by eating red food.
- 🥇 **Golden Food:** Appears randomly, gives **5 points** and speeds up the snake for 2 seconds.
- 🟢 **Passable Walls:** Snake wraps around the screen edges.
- 📱 **Mobile-Friendly:** Touch buttons and swipe gestures for easy control.
- ⏸ **Pause/Restart:** Pause and restart buttons work on all devices.
- 🖤 **Snake Head with Eyes:** Visual head to track direction.
- 📈 **Gradual Speed Increase:** Normal food gradually increases the snake's speed.
- 🎨 **Presentable UI:** Background, score display, and clear game layout.

---

## How to Play

### Desktop
- Use **Arrow keys** to move the snake.
- Click **Pause** to pause/resume the game.
- Click **Restart** to reset the game.

### Mobile
- Use the **on-screen directional buttons** or **swipe gestures** to control the snake.
- "Swipe To Start" appears on mobile before the game begins.
- Tap **Pause** or **Restart** for game control.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. **Optional:** Use VS Code **Live Server** to run it locally on multiple devices on the same network.

## Customization

- Adjust canvas size in `index.html` `<canvas>` tag.
- Change snake and food colors in `snake.js`.
- Modify speed progression in `snake.js` to make the game faster or slower.
